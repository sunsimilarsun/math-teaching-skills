# 产品适配与核对

此参考描述需要查明的差异，不内置某个私人库的路径、字段版本或格式快照。

## 进入一个目标库

从用户提供的根目录或仓库入口查协作说明、规范索引及产品登记，再读有关题卡／原生TeX／元信息位置／字段映射／来源处理规则。规范不可访问时说明缺口，继续可完成的来源清点或候选工作；不能宣称符合未知规则。

确认四件事：唯一题文存在哪里；稳定ID与出现键如何关联；答案、解析、角色和资源由哪一层负责；当前任务是否允许修改主源或仅候选。

## 常见产品差异

| 对象 | 必查差异 |
| --- | --- |
| 原生TeX自含题块 | 角色环境是否包住完整题目；ID是宏显示还是独立事实源；不要一律剥掉外层或再套一层。保留数学环境、注释转义、未知产品宏的待核状态。 |
| 装配型复习题库 | 单题可能只有题型片段，装配层提供角色和显示信息；调用参数可能是出现键而非ItemID；资源根属于被调用题，不一定属于当前主题。 |
| 同步增量返回包 | 审核交接表不等于正式Item Schema；先对照来源及已有身份，再按现成制作流程接入。教学顺序变化不改原序证据，不以例题／变式配额臆造题目。 |
| Markdown题卡 | 以当前题卡规范确定字段及客观题／解答题的答案层；保留已有稳定ID和兼容关系，不机械用结构化导出覆盖正文；模板ID复制后不能原样使用。 |

## 来源与重复判定

- 来源定位、原稿所称出版来源、来源认证是不同证据。只有文件名时可以记录文件名，但不能据此认证考试年份或版权归属。
- 字面同题但附加小问、论域或图形条件不同，不先合并；记录差异与建议。只有解答不同可能是解答版本冲突，不能靠新增身份绕过。
- 数字变式、逆向问法或条件替换可以形成独立候选，但直接母题和题族仍需关系证据；角色取决于实际用途。
- 图像数量一致只是粗检。核对每个题号／子问引用的文件、位置、内容及归属；缺图会影响裁决时停止该题的完整性认证。

## 最小交接记录

按任务需要给出表格或现行登记，不另造强制Schema：来源定位 → 输入题／小问 → 已有ID或临时候选 → 处理决定及依据 → 资源／解答对应 → 未决事项。

若输入清单含10条来源出现，其中2条复用已有题、1条待核，应报告三类去向及唯一身份数，不把10条全称为新增入库或数学通过。
