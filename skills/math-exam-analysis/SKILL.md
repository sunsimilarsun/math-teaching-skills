# 数学考试与试卷分析

按用户指定的学生、考试和读者确定交付物。只要求核一道题、查分或审核旧稿时，直接给相应结果。多名学生同卷可共用题目复核，逐人的答题卡、分数和结论分别保存。跨多周汇总学习变化用 `stage-learning-feedback`，机构三页学习报告用 `learning-report-author`。

从用户指定的教学库进入 `数学教学/学生管理/README.md`，以下路径相对 Markdown 库根。读取 `规范/档案/试卷分析/试卷分析【规范】.md`，制作家长 Word 时打开 `Template/学生管理/试卷分析/试卷分析【模板】.docx`。资料迁址时从项目导航或按文件名查找。旧成稿只作交付示例。规范内“本次第 2 题”“第 1—4 页”等文字属于当时案例，须换成本卷真实情况。

## 从卷面还原可核实的表现

1. 对齐学生、考试、卷别、考试日期和页次，分清原题、正式答题区、卷面草稿、阅卷批注和后来订正。教师提供的总分可以注明来源单独登记。单有试卷，可分析考查内容；单有成绩，可核对成绩记录。对缺页、照片模糊、未提供评分的部分分别列明缺项，继续处理可辨材料。
2. 按实际题号与小问核查；题意、图、答案或评分有争议时先独立核算，并保留校方实际给分和待核理由。逐题记录可用“题号／小问｜满分、实得与依据｜可见作答与位置｜已正确步骤或首个偏差｜待核／下一步”。漏页写“未见答题页”，拍到且可辨的空答区才写“空白”。正式卷和草稿不一致时两处分别记录。一个上游错误导致后续结果错误，归因时记一次；承认数学等价的其他解法。
3. 按本场规则处理多选的漏选、错选与部分分；主观题区分小问分、题目小计和整卷总分。总分、题型小计、题分与满分分别列算，同一批注只计一次。材料齐时对账；仅有部分分题记录时列“已核小计／仍待核题号”。不得把与总分的差额分摊到题目；两种批注释读即使同样凑出总分，也须保留各自依据。得分率给出分母，排名只引实有的群体及名次。总分冲突时并列来源，等待能区分口径的原记录。
4. 优先写 1—2 个有题号支持、能改变下一步教学的卡点，保留学生已做到的步骤。原因未明时给能区分解释的短追问，需要时请学生回看评分卷，说清从哪一步改、下次怎样检查；把自述记作自述。有复测任务时交代换题、允许支持与达标表现。看过订正、重做原题和隔后独立完成新题各按实际记录。

## 按读者交付

- **教师内部核查。** 保留来源页、批注释读、缺失证据、候选教学措施和审核状态。完整分析可把逐题表与审核、复测记录合在一份工作单。新证据改变结论时同步修订受影响的合计和家长稿，保留更正依据。
- **家长版信息。** 标题区识别学生，五栏正文省去学生姓名。标题下列考试日期、分析日期和任课教师。任课教师按已知姓名填写，未明确时按项目约定填写或留待确认。五列表头依次为“学校、考试类型、试卷满分、考查范围、成绩与定位”。实际范围与分数依据材料填写，有定位材料才写名次。考试时间按证据粒度写，已知月份或学期就写到该层级，缺少可靠信息的字段可省去相应文字。
- **家长版成文。** 以任课教师向家长说明本场考试的方式写成可直接转发的 Word。证据有缺口时，写有依据的最可能情况，收窄表述到能支持的事实。确有冲突且有明确核定的总分时，可写该总分，省去未能对账的分项。具体日期、名次、分数和教学承诺以真实资料为准。需要澄清时直接问用户，或在交付消息另附给教师的简短说明。原始来源、证据缺项、审核状态和制作说明保留在教师内部工作单。
- **完整家长版五栏。** 用动作替代评价。保留学生做对的步骤，只有结果时如实写结果。题号和具体步骤支撑本场能看出的知识、方法、数学思想和检查习惯。归纳具备可观察依据的表现，长期习惯或跨题掌握程度用独立复测或持续记录判断。
  - **整体**交代考试与主要得分分布，末尾用一句话概括本场体现的整体掌握情况及仍需加强的任务。
  - **优势**给出代表性题号和已完成的步骤，末尾用一句归纳本场作答体现的优势或可沿用的方法。
  - **问题**从 1—2 个教学上值得优先处理的卡点入手，写清题号、出错或未写全的步骤及其影响，末尾用一句归纳这些作答反映的共性问题。
  - **措施**写清课堂要调整的侧重点、要增补的练习类型及如何查成效。结合本次证据确定执行人、任务量或频次、复查节点及达标动作。未落实的安排写成自然的教学建议。已明确的日期与承诺按实际填写。
  - **总结**收束整场考试，连贯交代可沿用的方法、近期补强的顺序和有依据的复查方向。复查已安排时写清验收线索，未安排时写到本场证据能支持的判断。
- **正文篇幅。** 完整家长版五栏正文合计约 560—630 个非空白字符，上限 630，含标点与数字。标题、信息行、表头、栏名、页脚不计。证据少时可以更短。去掉同义解释和套话，再按母版排版。只审核、定向改稿或排版时按用户要求处理。
- **出稿前核对。** 像拿着答题卡向家长说明一样通读五栏。正文主语能省就省，直接写卷面上的步骤和结果。只有省略后分不清谁作答、谁批改或谁订正时，才写“学生”“阅卷老师”等称呼。学生姓名仍只放在标题区。把题号、小问、实得和满分、原作答和讲评后订正对回内部工作单。把几处同类表现归纳为可训练的行动。只见选项时记录选择，工作单保留具体批注、争议及待核项。缺项和需教师决定的事项留在内部工作单或交付消息。家长文件的标题、信息行、正文、页脚、文件名及文档属性采用正常成稿写法，清理“草稿”“待核”“待补”“待确认”“来源”等内部标记、提示文字、批注、修订痕迹和制作标识。
- **版式与放行。** 以现行 Word 母版副本制作 A4 横向单页（约 297 × 210 mm）。沿用品牌图、五列信息表、五栏正文及页脚。重点短语统一用 C00000 红色加粗，遇到跨文字片段的占位应完整替换。用 Word 打印预览或渲染为 PDF 后查看整页，核对实际纸型、方向、页数、可读性、裁切、重点是否统一标红加粗，以及是否清除占位、内部批注和制作标识。超页先压缩正文。对照规范 A1—A10 记录“通过／需修改／待补资料”，分别核实教师确认、版式预览和发送状态。
