# 数学试卷分析书写与审核规范 v1.2

> 教师内部使用｜2026-11-26 修订｜家长版沿用正式 A4 单页 Word 模板。

**总原则：以试卷确定考查范围，以答题卡确认作答，以评分记录核定得分，以复测判断后续掌握。**

## 01 适用范围与交付物

本规范用于高中数学月考、期中、期末、章节及阶段性测试。家长版在[正式 Word 模板](../assets/试卷分析【模板】.docx)副本中填写，默认采用 A4 横向单页（约 297 × 210 mm）。

| 产物 | 用途与交付对象 |
| --- | --- |
| 家长版 Word | 以“整体、优势、问题、措施、总结”五栏说明这次考试的表现、教学调整与复查办法。 |
| 教师内部逐题核验表 | 按题号和小问记录作答、得分、证据位置、首个偏差和待核项，供教师核查。 |
| 审核及复测记录 | 保留事实、评分、版式与教师确认情况。复测实施后另记结果，可与逐题表合并。 |

## 02 原始资料与核查门槛

| 资料 | 应核查内容 | 不足时的处理 |
| --- | --- | --- |
| 试卷原件 | 所有页、题号、题型、分值、题设和附图是否完整 | 只做题目范围分析，不作个人得分归因 |
| 答题卡/书面解答 | 客观题涂卡、主观题步骤、空白、涂改、草稿归属 | 不能以试卷上的勾画替代正式作答 |
| 评分记录及规则 | 分题实际得分、阅卷痕迹、主观题分步给分、多选给分标准 | 教师内部记下缺项。家长版使用已提供的总分或题型合计，单题分只写有依据的数值 |
| 参考答案与题目复核 | 答案来源、数学独立复核、题意歧义和命题异常 | 争议题单列待教师核定，不作确定失分结论 |
| 考试基本信息 | 姓名、学校、考试名称与日期、满分、范围、时长、实际成绩 | 用已有事实填写，家长版缺少依据的可选字段留空或省略 |
| 历史记录（可选） | 同范围、同难度、相近作答条件的可比成绩或复测 | 无可比资料不写“明显进步/退步” |

家长 Word 按可以直接交给家长阅读的成品撰写。对有多种解释的一步，采用题干、作答和教师记录最支持的判断，用自然的教学语言写出目前最可能的情况，并把判断限定在这次考试。只有成绩汇总时，写能够确定的得分表现。对解释影响较大的疑点可以直接询问教师，或随交付另附一段给教师的说明。来源、其他可能解释和核查进度记入教师工作单。

## 03 逐题记录及判断规则

| 逐题字段 | 填写规则 |
| --- | --- |
| 题号／题型／分值 | 照卷面登记，分值或选择规则有疑问时复核原件 |
| 知识点／方法／能力 | 最多保留 1—2 项主标签，避免一题泛化为多项能力缺陷 |
| 书面作答证据 | 分别记录涂卡、答题区域步骤、试卷草稿；写清可辨与不可辨部分 |
| 得分与结果 | 照批改记录登记“实得／满分”，不得根据最终答案擅自补主观题分 |
| 作答状态 | 正确／错误／部分有效／未完成／空白／字迹不清／待核验 |
| 典型卡点 | 用“出现了什么”描述，如漏检定义域、参数分支遗漏、推导断裂 |
| 原因判断 | 已证实才写成原因；若仅见结果，写“可能与……有关，待复测” |
| 后续动作 | 针对卡点给出一次复练或辨析任务，并说明是否需要独立复测 |

正确答案不代表过程必然正确；写出正确切入点不代表已完成整题；未填写最终结果也不必然等于完全不会。若答题卡与卷面演算不一致，以正式作答和阅卷规则为评分依据，并将卷面演算保留作辅助诊断。

多选题按本次官方给分规则处理：漏选、错选、部分选择如何计分必须核实，不能固定套用某一种标准。主观题以实际阅卷或评分细则核准分步分；遇到题意不清、选项重合或标准答案争议，先登记争议题，不据此判断学生知识缺陷。


## 04 失分归因与问题优先级

| 诊断层级 | 允许表述 | 禁止越界 |
| --- | --- | --- |
| 事实 | “第×题定义域未核对”“第×题列式正确但未比较两段最值” | “因此学生平时不认真” |
| 判断 | “本次函数同一性判断中条件检查不充分” | “整个函数模块基础很差” |
| 待核查 | “是否由于概念不清还是考场遗漏，需同类独立复测” | “肯定是粗心／时间不够” |
| 计划 | “拟安排分类讨论专项训练，教师核定题量后实施” | 将未确认的课次、频次及分数目标写成承诺 |

错误类型可记录为：概念条件、方法选择、符号与运算、推理与等价变形、分类讨论、建模迁移、书面表达、审题遗漏、时间分配（需时间证据）、未作答／无法判定。每题优先标主因与次因；“粗心”“态度差”“天赋不足”不是无证据情况下可用的失分分类。

家长版通常只保留 1—2 个核心问题。优先级参考：①涉及基础题或可恢复分值；②是否为后续模块前置能力；③是否在多题重复出现；④是否可通过短期复测明确验证。不能仅因难题分值高就将其列为首要弱点。

统计成绩时区分“卷面得分”“题型得分”“得分率”和“历史变化”。后两项必须有明确分母与可比条件；没有班级分布、位次或校内线，不写“处于班级前列／中下水平”等推断。

## 05 家长版表头与五栏写法

标题用学生实际姓名加“数学试卷分析”。文件名用学生姓名、考试名称和分析日期。标题区列考试日期、分析日期、任课教师。考试日期按本场材料填写，未知时留空或省去该项，分析日期填实际整理日。任课教师有明确姓名时按实际填写，未指定时按项目约定填写。

顶栏从左到右为**学校、考试类型、试卷满分、考查范围、成绩与定位**。学校填本场考生所在学校，考查范围按试卷概括。“成绩与定位”填实得分与得分率，有可靠的校内排名或可比群体数据时再补定位。学生姓名只在标题识别，五栏正文省去姓名。

| 栏目 | 写法 | 篇幅参考 |
| --- | --- | ---: |
| 整体 | 交代本场考试和得分分布。末句概括整体掌握情况，点出本卷哪些内容掌握较好、哪类任务仍需加强。 | 90–100 |
| 优势 | 选一两个有代表性的题号，说明做对了哪一步，用到了什么知识、方法或思想。末句归纳这些作答体现的优势及其适用范围。 | 90–105 |
| 问题 | 选一两个影响后续学习的卡点，用题号定位到作答中的一步，说明反映出的知识、方法、数学思想或检查习惯。末句归纳这些失分背后的共性问题。 | 150–175 |
| 措施 | 从共性问题确定下一步课堂侧重点。写清教师如何调整讲解、示范或选题，学生加练哪类题、练多少或多频繁，以及何时用什么新题、看哪些动作判定成效。 | 125–145 |
| 总结 | 联系全卷，写清已有的知识或方法基础、当下最值得先补的环节，以及通过什么新的独立作答判断能否迁移。把三者写成连贯的一段。 | 95–115 |

**五栏合计通常为 560–630 个字符，上限 630。** 只计五个正文格，去掉空格、换行等空白，标点和数字各计 1 个字符。已确认成稿为 612 个字符，依次为 96、101、169、136、110。分栏参考可按证据详略调整，正文较少时可以更短。优先保留有证据的判断、教学调整和复查办法。

读完前三栏的末句，应能分别看出整体水平、可以继续运用的优势和优先处理的困难。仅有正确选项时只记选对，方法判断须有解答过程支持。原卷作答、考后订正和换题复测分别表述，平时习惯或稳定掌握需有相应观察。

## 06 文字语气及视觉格式

| 项目 | 执行要求 |
| --- | --- |
| 措辞 | 像任课老师拿着卷子向家长讲题，用题号、具体步骤和课堂动作说明情况。通读时删去工具自述、生成过程、套话、占位提示和内部审核用语。 |
| 题号证据 | 问题与优势至少各有可核实题目或答题过程依据；不堆砌整页题号 |
| 重点标红 | 所有重点统一使用同一种红色（C00000）并加粗。选取能体现判断、目标或达标表现的短语，控制每栏的强调范围。 |
| 标题及配色 | 沿用机构 Logo、EF7B00 橙色表头、FFF7EE 浅橙标签栏，正文深色为主 |
| 页面与表格 | 正式母版采用 A4 横向单页，保留标题区、五列表头、五栏正文及页脚。核对 Word 节纸型和方向，打印预览或渲染后查看整页，检查页数、文字与表格边界。 |
| 字体 | 保持现行正式空白模板的字号、字型和行距；超页先删冗余，不继续机械缩小字号 |
| 数值与日期 | 使用实际提供的分数、排名及日期。只有总分时报告总分，已有总分与满分时可计算得分率。无来源的排名、分题分或考试日期留空或省略。 |
| 家长交付 | 正文省去学生姓名。检查文件名、标题、正文、页眉页脚、批注与文档属性，清除“草稿”“待核”“待补”等标签、未替换占位、生成工具痕迹和他人资料。给教师的说明单独交付。 |

用加粗短语提示家长先看哪一处。黑白打印时，通过同一处加粗也能识别重点。

## 07 教学措施与复测验收

先从本卷归纳一个可教、可检查的问题，再确定下节课要更多讲解、示范或练习的内容。安排应能看见教师如何教、学生如何练、教师如何复查。把改一道错题延伸到同类任务，让学生在新条件下独立完成关键步骤。

| 教学情况举例 | 课堂与练习调整 | 复测时观察 |
| --- | --- | --- |
| 能运用公式得出结果，书面推导缺少依据 | 教师用中档题示范如何由定义或题设推出关键等式，再用改变条件的短题让学生补写依据。 | 学生能否独立写出等式、说明每一步所用的条件。 |
| 含参问题遗漏边界，求出候选值后缺少检验 | 课堂比较一般情形与特殊情形，增练有分界点的题。讲评时逐一回到原条件说明解的取舍。 | 换一道未见题，观察能否列全分支并逐个检验候选值。 |

根据本场证据和教学进度确定课次、题型、题量或频次、复查时点和达标表现。教师已定的安排按实写明。尚在商议的安排用任课教师的口吻写成具体建议，课次和题量按已有安排或建议的含义表达。复测记录写明题目是否见过、允许的提示及首次作答表现。

## 08 审核清单与放行标准

| 编号 | 审核要点 |
| --- | --- |
| A1 身份考试 | 题名、学校、考试信息、成绩来源和任课教师填写符合表头约定。 |
| A2 答题证据 | 各项判断均能在已提供材料中找到依据。教师工作单注明依据来自试卷、答题卡、评分记录或教师转述，以及需要进一步核对的部分。 |
| A3 得分计算 | 题型、每题分值、客观题涂卡和主观题分步给分核实；争议题单列 |
| A4 推论边界 | 独立完成／提示后完成／起步有效／未完成／空白等未混淆 |
| A5 问题聚焦 | 只有 1—2 个核心卡点；题号证据与所写判断一一对应 |
| A6 归因谨慎 | 没有无依据的粗心、态度、智力或考试心理归因 |
| A7 措施对应 | 课堂调整和加练回应本卷问题，执行人、题型与题量或频次、复查时点和可观察的达标表现清楚。已定与拟议安排用语准确。 |
| A8 全文一致 | 前三栏各有一句结论，末栏总结串起已有基础、首要问题和复查方向，题号与判断和内部表一致。 |
| A9 版式与家长交付 | 实际预览为 A4 横向单页。核对正文字符数、五列信息与五栏正文、Logo、页脚和统一的红色加粗重点。检查文件名、正文及属性中有无内部标签、批注、占位或生成痕迹。 |
| A10 教师确认 | 原始事实、诊断与后续安排经任课教师核对；保留审核日期 |

“通过／需修改／待补资料”仅登记在教师内部审核记录。核查身份、数值和措辞，纠正与材料冲突的事实，按证据范围调整结论。涉及评分口径或安排的实质分歧，单独向教师提问或说明。Word 成品预览后再登记版式检查结果。

审核流程：①读试卷与题目复核 → ②对照答题卡和评分 → ③内部逐题登记 → ④聚合 1—2 个核心问题 → ⑤教师确认计划 → ⑥五板块成稿 → ⑦独立审校 → ⑧Word 渲染与隐私检查 → ⑨归档。

## 09 补证与归档

收到补充卷页、答题卡或评分细则后，对回内部逐题表。新证据改变判断时，同步更正有关分数、题型小计、归因和家长稿，并保留来源。

家长 Word 按学生姓名、考试名称和分析日期归档。逐题核查及审核、复测记录标为“内部”，可合并为一份教师工作单。分别记录文稿已预览、教师已确认和已经发送的实际状态。
