# 教学库规范适配

此公开版不依赖任何私有仓库。使用者应指定教学库根目录和适用规范；未提供时不要假定已经掌握本地约定。

## 最小查阅链

1. 目标项目的 `AGENTS.md` 或等效协作规则。
2. 内容总规范与产品规范索引。
3. 本次产品的讲义模板、属性字段/类型、题目身份和来源规则。
4. 实际蓝本正文与引用资源。
5. 输出工具的当前语法、版本和有效设置。

一些项目可能使用 `_system/规范/README.md`、`模板&规范/讲义/讲义属性规范.md` 等路径；这些只是示例，不是必需布局。以项目内实际入口为准。规范找不到时列出缺口，仍可完成不依赖该规范的内容草案。

## 需要确认的差异

- 属性字段与类型、标题唯一来源、未知值的表示方式、历史字段保留规则。
- 同步、复习、专题、试听、模型与大学阅读各自的结构及目标。不将一类产品的固定课时、题量、例题变式配额套给其他产品。
- 新编与既有稿修订的范围不同；不能为了统一模板批量改动已有内容。
- 概念辨析、条件转化可按产品要求设计，但完整证明、解释、作图和混合小问不能被格式要求截断。
- 独立检测需要未展示任务；历史接触不明时保持待核。
- 标准答案与补充解析的归属、图像引用、题块级别及稳定锚点须按当前契约执行。

规范是用户项目的事实源，此文件只帮助定位差异，不维护第二套知识正文或固定个人工作流。
