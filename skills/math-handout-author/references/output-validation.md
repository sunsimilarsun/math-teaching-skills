# Mathsemble 输出与验收

先读取当前产品代码规范及本机实际 Mathsemble 版本/设置；不要假定候选源码已经安装。普通 Obsidian 折叠不等于学生答案已删除。

若项目采用以下 Mathsemble 约定，可据此适配；必须先与实际版本、项目规范和配置核对：
- 共享题文、知识和必需图表显示；共享知识 Callout 不带 +/-。
- 内联 `?{}`、`!{}` 保存答案；学生版隐藏答案保留作答位置。
- `[!answer]-` 保存标准解答；教师版显示，学生版按实际配置保留作答区。
- `[!question]-` 思考追问、`[!teacher]-`、`[!scaffold]-`、`[!solution]-` 按当前导出选择显示/隐藏；`+` 不能当教师专属标记。
- 教师层中嵌套的题答和图一起归属，不把解答图放到共享区。

作者应写明确的块边界：答案引用每行保留对应 `>`，块间留明确空行，避免列表深缩进隐藏块及含答案槽的跨行行内代码；需要展示语法时用同行代码或围栏。不要把这个保守作者策略当作完整 Markdown 解析器。

实际安装版本与修复候选可能不同。每次输出前重新确认有效版本和显示设置，不能沿用历史自动测试宣布宿主或 PDF 通过，也不擅自部署插件。

## 验收层

1. 静态：属性类型、题块/小问/答案对应、链接目标、图片数与资源、公式围栏和引用层级。
2. 数学：每题过程和结论独立核验；绘图条件、反例与定义域检查。
3. 投影：实际版本学生/教师内容是否完整或应隐藏，未知图形/插件输出单列。
4. 宿主与产物：Obsidian、MathJax/TikZ、双版PDF及打印各自核查。没有实际运行就 NOT_RUN。
5. 教学：用时、学生独立性、提示和复测来自真实课堂，不由文件结构推导。

母稿折叠答案仍可展开，不能直接当无答案检测卷。保护必要作答空间；自然分页允许长答案跨页，不能用删步骤或压缩空间换成功导出。
