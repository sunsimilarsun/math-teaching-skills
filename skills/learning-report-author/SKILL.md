# 学习报告制作

把课堂、作业、试卷、成绩与教师观察整理成家长阅读的三页 Word 学习报告。学情判断要能追溯到学生的表现，教学安排要回应具体学习需要。用正式模板制作，定稿时逐页预览。

## 模板与依据

从用户指定的教学库进入 `数学教学/学生管理/README.md`。下列规范与 Word 母版路径相对 Markdown 库根，学生档案与课堂记录路径相对 `数学教学/学生管理/`。先核对规范与 DOCX 的版本。历史学生成品可用于了解表达习惯，不能作为另一名学生的底稿或事实来源。

- 规范：`规范/档案/学习报告/机构学员学习报告_生成规范与模板标准_v3.2.md`
- 版式模板：`Template/学生管理/学习报告/机构学员学习报告_标准模板_v3.2.docx`
- 学生档案：`学生【在读】/<姓名>【档案】.md`（六维画像、综合评语、突破策略、当前重点）
- 课堂记录：`学生反馈/上课记录表.xlsx`、教师提供的周反馈采集表或工作台中该生相应时段的有效实录。已起草的反馈应追溯原记录，同一事件不重复算作独立证据。
- 逐题核查/试卷分析（如有，作成绩证据）

新建报告时，在本次可用材料范围内查阅对应学生档案，与教师提供的姓名、年级、学校和进度对照。未建档或仅提供临时材料时，可按下文最低条件起草；资料缺项在教师清单说明。来源有冲突时保留可确定内容，把冲突项列给教师。家长版的封面和基本信息栏可沿用模板下划线留空，内部草稿或随附的待补清单可写“待补”。模板引导语中的“认真勤奋”“周中打卡”等仅为示例，不能当作该生表现。

## 触发与适用

- 用户要机构三页 Word、按指定模板制作学习报告，或只改已有报告的一栏、一处格式，使用本 Skill。普通阶段学情分析或家长阶段反馈用 `stage-learning-feedback`，单周五段家长反馈用 `weekly-student-feedback`，一场考试的逐题核查与试卷分析用 `math-exam-analysis`。需要针对某个学生设计追问或复测时可用 `math-learning-diagnosis`。先看用户指定的成品；报告有成绩栏并不自动要求另做一份试卷分析。

## 输入信息要求

理想输入（能写满三页）：
1. 学生姓名、年级、就读学校、任课老师、班主任。
2. 本阶段上课内容与进度（已学模块、当前到哪）。
3. 课堂表现事实（专注、互动、独立/提示后完成、典型卡点）。
4. 作业/检测/试卷证据（完成率、正确率、具体得分或阶段检测结论）。
5. 最近正式成绩（日期、得分、满分、排名/参考人数；没有就留待补，不编数字）。
6. 拟定的教学计划（模块顺序、课次；或授权我按进度规划）。

新建报告供教师审定时，至少要有明确身份、一项本阶段有证据的表现，以及教师确认的辅导方向或用户授权拟定的方向。拟定内容标为建议。单纯修改既有报告的字体或格式时以用户给定文件为底稿，无须重新收集与改动无关的材料。新建时缺关键项：
- 可先完成有证据的部分，交付说明标注“内部草稿，待教师审定、未发送”；
- 缺的成绩、学校、班主任等按上述家长版与内部草稿的处理方式留空或标待补；
- 同时产出**待补信息清单**（下表式），供教师补齐后重出报告。

## 固定三页结构（不得改动）

### 第 1 页 封面
机构｜学员学习报告｜任课老师｜班主任｜时间，橙色几何品牌版式。封面不放成绩、学情结论、课程规划。

### 第 2 页 学习反馈（表格，栏目固定）
1. 学员姓名、年级、就读学校
2. 辅导科目
3. 近期学习及状态反馈（绿色通栏标题）
4. 近期成绩记录及反馈
5. 辅导方向（左窄标签列 + 右侧正文）
6. 学习建议

### 第 3 页 教学计划（三列表格）
`序号｜教学内容｜预计课次`，附"（实际教学计划可能会根据学员掌握情况略有调整）"，底部备注。

## 内容提炼原则

### 证据优先，不臆造
所有判断回指课堂表现、作业、试卷或阶段检测、已学内容、正式成绩、教师观察。材料没给的信息不得自行补写；对成绩、排名、学校、行为或进度有疑问时，记入教师待补清单。

### 四类问题诊断
1. 知识缺口（概念、性质、公式没掌握）
2. 方法缺口（懂知识但不会选方法、组织步骤）
3. 执行问题（思路对但计算、符号、书写、步骤不稳）
4. 迁移问题（熟悉模型能做，条件变了不会独立调用）

诊断后必须对应具体教学动作。

### 独立程度边界（勿混淆）
听懂＝能跟上讲解；跟着做＝提示或示范后完成；独立完成＝无提示完成；稳定掌握＝隔时或换题仍正确。**不能把提示后完成写成独立完成**，不把"听懂/看懂"写成"会做"。

## 家长稿共用写作规则

- **用动作替代评价。** 写学生在具体任务中做了什么，哪一步独立完成，哪一步用到了提示。记录只有结果时就写结果，不补过程或推测原因。
- **不强行凑首尾。** 保留规定的称呼、栏目和固定文字。可改的正文从本栏要说的事实或安排写起。一句开场评价或结尾展望如果没给家长带来新信息，就省掉。

## 各栏推荐组织

**近期学习及状态反馈**（通常 3 项，不机械凑）：
1. 学习内容 2. 学习状况 3. 知识与方法
必要时加"近期进步"，但只在有事实时写。
（注：模板引导语为「1、学习内容：近期主要学习内容、知识点掌握程度（课上吸收情况、课后作业完成度、薄弱点）」「2、学习状况：认真勤奋、学习态度、精神状态、主动问题、周中打卡、交流沟通」「3、知识与方法：当前已学内容、掌握边界，以及知识、方法、执行或迁移方面的核心问题」。）

**近期成绩记录及反馈**：有正式成绩时核对考试、日期、得分与满分；不同满分或试卷未经可比性核实，不能直接推出提分幅度。缺正式成绩时可写已核实的阶段检测或作业表现，并注明来源。连替代证据也没有，则留空或在草稿中标待补，不凭空断言学校未考试。

**辅导方向**（3 项，按"问题 → 教学动作 → 达成证据"组织）：
1. 基础/知识收口 2. 方法/执行训练 3. 阶段复测、迁移或后续衔接
每条给出可验证的"达成证据"。

**学习建议**：课前—课中—课后三个可执行动作。

## 表达风格与偏好

- 面向家长，语气客观、委婉、有分寸；优点用事实体现，问题说清楚但不贴标签、不否定人格、不夸大进步、不保证提分。
- 家长版正文直接写可证实的情况，待核项目列在教师用清单。缺少正式成绩时，只有教师已确认后续安排，才向家长说明补充时间或方式。
- 信息密度适中：不堆砌课程时间表与日期，不罗列每个课次；点到核心，家长读得进。
- 正文**不加粗黑体堆砌**，重点靠少量红色；每个自然段 1—2 处红色为宜，优先标核心困难、明确优势、关键教学动作、阶段目标，同一结论不重复标红，标签/表头/课程计划不用红。
- 每名学生独立处理，不套用他人表述；无差异证据时不强造辨识点。

### 出稿前文风校对

事实核对完、定稿排版前，按家长独自翻阅报告的顺序通读可改文字。保留正式书面语，有教师审定稿可参考其用词。只调格式时保留原文。

- **主语能省就省。** 第二页写作答表现、第三页写教学计划时，先省去重复的姓名、“孩子”和人称代词，再连读。只有分不清谁练习、谁安排或谁复查时，才保留姓名或称呼。
- 读第二页时，家长应能指出孩子做对了什么、在哪一步用到了提示。“基础收口”等内部说法改到题目和步骤上，必要的数学术语照用。再对读第三页，看相关教学单元能否回应第二页已写明的辅导重点。计划栏用简短的课程名称和任务。
- 例如，记录是“三道分式方程独立解对两道，第三道提醒后才验根”。可以写成“三道分式方程中，有两道独立做对。第三道经老师提醒，才把求出的值代回原方程检验。”这条记录只支持本次表现；没有前后可比材料，就删去“取得了稳步进步”。
- 朗读第二页时，把只为对称而成对出现的评价拆开。表格已交代话题，段落可以直接从观察写起。说明条件、转折或因果的连接词按需保留。用有依据的表现肯定学生，删去替家长宽心的话和提分保证。
- 对回数字、成绩来源、独立程度和课次。未测的内容若影响结论，就写清已测到哪一步。原因或成绩待核时列入教师清单。第三页区分拟议与已确认的安排，保留栏目标题、固定备注及用户指定保留的原句。

## 教学计划（第 3 页）规则

- 一般规划 **15 个教学单元（15 次课）**，可按学生情况增减；增减数据行必须复制现有行样式，不重建表格。
- 一次课是完整教学单元，组合 2—4 个紧密关联知识点/方法，不把碎片知识拆成单独课次。
- 命名：`模块/能力单元：核心内容或训练目标`（如"平面向量基础：基本概念、坐标运算、共线与模长"）。
- 后台按每次课约 2 小时估容量，**报告中不显示时长**。
- 末尾加备注："具体的上课进度会根据孩子的实际上课情况进行调整，中间也会穿插知识点复习。"
- 计划要与学生当前进度衔接（从当前模块往后），必要时与学校复习进度保持同步。

## 生成实现规则（最高优先级：版式保护）

1. 新建时复制正式 v3.2 DOCX；定向修改时复制用户指定的既有报告，按 v3.2 核对允许改的项目。修改副本的原表格、原单元格、原段落，并保留节属性。文字若横跨多个 run，只替换目标文字并保留字体、颜色和图形锚点。格式修改只改相应属性，保留原文字。
2. 不重建表格、不重设栏目、不改列宽/行高/合并单元格/边框/底色/边距/分页/封面图形。
3. 只改任务明确要求改的项目：说"改字体"就只改字体字号；说"优化文字"就只改文字与红色范围；说"调整教学计划"就只改计划标题/内容/课次/行数。
4. 程序级禁止：按文本长度重算列宽、`autofit` 漂移、自动缩小字号、为分页合并/拆分单元格、切换表格样式。

## 质量检查项（渲染验收 + 复核清单）

生成后必须逐项核对：

**版式**
- 仍为三页、无空白页；封面图形不漂移；第 2 页表格、第 3 页三列表结构与模板一致。
- 无断表、文字裁切、边框缺失、列宽变化、单元格意外合并/拆分。
- 各页字体字号符合上表；无自动缩小字号。

**内容**
- 事实与材料一致，无虚构成绩/排名/学校/学习行为。
- 学情判断能回指证据；区分知识/方法/执行/迁移四类问题。
- 辅导方向与诊断对应；学习建议具体可执行；课程计划以完整教学单元组织且与进度衔接。
- 不显示后台课时估算；独立程度表述未混淆。

**交付前**
- 把成品渲染为 PDF 或逐页图，打开封面、反馈页、计划页查看。可用本机 Word 导出，或用可用的 LibreOffice 与 PDF 渲染工具。不要以 DOCX 元数据中的页数替代实际预览。若溢页，在可改文字的任务中先精简重复表述后重新渲染；纯格式任务超出授权范围的文字或模板布局调整，先向教师说明。没有可用渲染器时交可编辑草稿，写明尚未完成逐页检查。
- 姓名/学校/年级/成绩真实准确；无他人姓名、内部批注、审核编号、占位符泄漏。
- 家长版由教师审定后发送；草稿明确标注"待教师审定，未发送"。

## 工作流

1. 确认是新建报告还是定向修改。新建时查规范、模板及本次可用的身份和表现资料；定向修改先核对指定原稿、范围和对应规范。
2. 需要编写或修改学情内容时，按对应学生和时期整理课堂、作业、成绩、教师观察，区分已证实与待补。
3. 写学情时，从有证据的知识、方法、执行或迁移问题出发，把学习反馈、辅导方向和建议落到相应栏目。
4. 新建时按模板三页填充，计划通常排 15 个单元并按实际情况增减；修改时只动用户要求的栏目或格式。
5. 凡涉及文字，按“出稿前文风校对”核对可改段落，再逐项检查并渲染预览全部 3 页。
6. 交付：成品 docx（命名 `姓名_机构学员学习报告_日期.docx`）+ 若有缺项附内部待补清单。

## 边界

- 只写有证据的事实，缺失信息按交付对象处理。
- 家长版不出现内部术语、其他学生姓名、内部批注、审核编号。
- 周反馈、逐题试卷分析、逐生学情诊断分别走各自专用规范，本 skill 不越界。
- 教学计划中"拟议"与"已确认"分开，未确认的安排不写成承诺。
