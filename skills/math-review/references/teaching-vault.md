# 教学库适配

## 运行时读取顺序

先确认用户指定的真实教学目录及当前版本，不以工程示例数据、工作台说明或历史报告替代教学正文。不要凭本文件假定本地与远端同步。

从目标项目读取：
1. `AGENTS.md` 或等效协作规则。
2. 内容总规范、产品规范索引与目录登记。
3. 本次所属产品规范及引用资源；修改前读取适用的写入／代码规范。

示例规范位置可以是 `_system/规范/内容规范.md` 与 `_system/规范/README.md`，但不是公共 Skill 的硬性依赖。规范缺失时可继续通用数学检查，不能伪造项目格式要求。

## 需要按项目确认的适配点

- 稳定 ID、候选／待审状态、来源证据与资源归属。实质不同的改编不静默覆盖旧身份；母题关系不凭相似题面猜填。
- 标准答案与补充解析的职责。若项目要求答案层完整，不能仅以教师解析中有结论判定答案完成。
- 数学分数采用项目规定的分式写法，例如 `\frac`，不改变变量或题意。
- 各产品的讲次、题组、来源保留和版本规则不同；不强加统一课时、六段结构、题量或输出接口。
- 格式、数学、来源、图形、真实宿主、PDF、打印与课堂分别验收。插件安装版与候选可能不同，源码检查不能替代输出检查。
- 避免无必要的重复正文、恢复包及版本维护门禁；必要备份与来源留存遵循项目要求。

此参考文件只说明如何适配，不包含私有库路径、私人对话或实时项目状态。
