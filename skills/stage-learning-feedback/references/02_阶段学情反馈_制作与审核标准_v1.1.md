# 阶段学情反馈：制作与审核标准 v1.1

> 版本：v1.1　｜　原制定日期：2026-09-14　｜　本项目修订：2026-11-26　｜　用途：教师内部使用

## 01  使用范围与固定结构

面向家长的阶段反馈，不是多份周反馈的拼接。

适用于暑期、月度、期中、期末、章节结束或连续若干次课后的阶段总结。正文回答四件事：学了什么、现在能做到什么、相较前期有什么变化、下一阶段怎么推进。

来源与新增规则：版式和栏目承接用户提供的《阶段学情分析样稿》第1页，保留基本信息栏及“整体—优势—问题—措施—总结”。本版沿用 v1.0 的证据、纵向对照、复查及审核要求，并按本项目约定更新家长版署名与日期。

### 1. 两类材料，分别使用

| 材料 | 用途与边界 |
| --- | --- |
| 家长版反馈 | 一份单页 Word。只呈现经确认的阶段结论、关键事实与后续安排；不放内部证据编号、原因猜测或审核意见。 |
| 教师内部工作单 | 记录原始事实、前后对照、问题与措施、待补资料及审核结果。保留在内部，不随家长版发送。 |

### 2. 基本信息

标题填写学生姓名；信息栏固定为年级、辅导科目、学习阶段、近期学习内容、学情定位。标题下仅列反馈日期和任课老师。任课老师按实际姓名或项目约定填写。家长版无需展示阶段起止日期。内部用月份、单元或课次定位本阶段，已知起止可记在工作单。跨升学阶段应写清“本阶段年级／下一阶段年级”。不默认补入学校、分数、课次或排名。

### 3. 正文五板块与篇幅预算

| 板块 | 必须回答的问题 | 建议字数 |
| --- | --- | --- |
| 整体 | 本阶段学习范围、当前表现及有依据的变化。 | 80–120 |
| 优势 | 在哪类具体任务中表现较好，依据是什么。 | 80–120 |
| 问题 | 优先解决的1–2个卡点；区分已观察问题和待核查项。 | 100–150 |
| 措施 | 谁做什么、做多少、何时复查、怎样判断达到目标。 | 150–220 |
| 总结 | 阶段成果与下一步重点；不重复全文，不新增判断。 | 50–80 |

> 建议正文约500–700字，字数不含基本信息。各段区间是写作预算，不要求凑满；不为压缩字数删去判断边界。通常只保留1–2个核心问题，措施部分应获得最多篇幅。

### 4. 责任边界

任课教师确认事实与计划；AI可协助整理、成稿和查错，但不能代替教师确认学生真实掌握程度。小规模使用无需增加岗位，可由同一教师分别完成内容审查和发送前检查。

## 02  资料与阶段判断标准

先确认记录支持什么，再决定反馈能写到什么程度。

### 1. 最低输入与缺失处理

最低输入包括学生身份、可辨认的学习阶段、实际学习内容、至少一条本阶段具体学习事实及其完成条件，以及教师确认的下一步安排。只有“较好、一般、认真、需努力”等评价词，不足以成稿。身份、阶段或具体事实缺失时先列补充问题，不生成貌似完整的正式反馈。

成绩、课次、题量等数据仅在有记录时填写，并注明日期及范围。没有考试数据也可以制作反馈；缺少历史可比资料时可以写当前表现，但不能声称“明显进步”或“持续退步”。

### 2. 四类信息分开记录

| 类型 | 写作规则 |
| --- | --- |
| 事实 | 写清日期或所在阶段、任务、完成条件和结果；标明来自课堂、作业、检测或家长／学生转述。转述不能改写成教师亲见。 |
| 判断 | 必须能追溯到上述事实，且结论范围不超过证据范围。一道题的表现，不等于整章能力；一次测验，不等于稳定状态。 |
| 待核查 | 尚未检测、记录不足或前后表现矛盾的项目，写明需怎样复查。未暴露问题，不等于不存在问题。 |
| 计划 | 明确属于未来安排。AI提出而未经教师确认的题量、频次、课期等，只能列为内部建议，不能写成已经确定的承诺。 |

### 3. 完成条件不能混写

区分“已讲授／已练习”“提示后能完成”“同类题可独立完成”“间隔后仍能完成”“能迁移到变式”。这些是观察条件，不是可凭印象升级的能力等级。稳定掌握需要不同时间、适当任务范围内的独立表现支持；没有后测时，不由教学覆盖量推定熟练度。

### 4. 与历史档案纵向对照

有可比记录：写“前期在什么条件下只能做到什么，本阶段在什么条件下能够做到什么”。比较时说明任务范围、难度、时间要求和提示程度；条件差异明显时不直接判断升降。

无可比记录：删去模板中的比较句，改写当前事实并列待观察点。历史问题未复查：保留“前期出现，本阶段尚未复查”的时间边界，不直接判为仍然存在或已经解决。记录冲突：先核对日期和完成条件，仍无法解释时标记待核查。

### 5. 原因和量化结果

不把错误直接归因于粗心、态度、智力或练习不足。确有线索但原因未证实时，说明依据和待验证条件；无必要可只写表现与措施。分数变化需核对试卷满分、范围和难度；正确率要有题数与适用范围，不编造数字，也不把不同满分、范围或条件下的结果直接作进退比较。

## 03  五板块写作与行动设计

每个判断有落点，每个核心问题有对应的后续安排。

### 1. 整体：范围＋现状＋变化

概括主要学习内容和教学任务，用关键事实说明当前水平，再写有证据的前后变化。没有可比资料时只写现状，不硬写进步。不要逐节课罗列，也不要把“完成章节”写成“全面掌握章节”。

### 2. 优势：任务＋表现＋能力范围

优先写1–2项有依据的优势，如起步判断、概念辨析、运算、表达或策略选择。必须交代独立完成还是提示后完成。单次积极表现可如实写出，但不包装为长期稳定优势；不能仅凭学习内容多判定学习容量或迁移能力强。

### 3. 问题：卡点＋事实＋影响

只列当前最影响学习的1–2项问题，每项都写到具体表现及影响环节。没有明确问题时，不为填满版面编造不足，可写“现有记录尚不足以判断该项稳定性”，再安排核查。优先级依据后续学习的前置需求和实际影响，不给学生贴固定标签。

### 4. 措施：六要素与推进条件

每个核心问题都要对应：处理目标、责任人、具体任务、执行量或频次、复查时间、可观察的达标表现。课堂与课后任务分工明确；家长只承担确有必要、负担可控的协助事项。没有第二问题时删去相应句子；未达到前置目标前，不直接跳到更高难度。

> 写法示例，非样稿学生的真实安排：针对已记录的因式分解起步困难，教师先示范如何判断首步；学生课后每周2次、每次10分钟练习同类题。两周后用未练过的同类题独立复查，观察能否说明首步依据并完成运算、是否仍需关键提示。示例频次与时长须由任课教师按实际情况确认。

### 5. 总结：成果＋首要目标＋推进条件

用1–2句收束：肯定已证实的成果，明确接下来最重要的目标，以及何时根据复查结果调整。不得加入正文未论证的新优势、新问题或确定提分承诺。

### 6. 学情定位与学生差异

“学情定位”使用“具体能力现状＋待突破点”，例如“常规题较稳，综合迁移待加强”；示例仅展示措辞，需有相应证据后才能套用。资料不足时暂不定性，不用单独的“优秀／较差”代替说明。

| 教学重点 | 同一模板内调整观察与验收重点 |
| --- | --- |
| 基础巩固 | 概念与起步、关键步骤、运算、提示能否逐步减少。 |
| 常规提升 | 独立完成、正确率的适用范围、书写规范与合理用时。 |
| 培优训练 | 策略选择、变式迁移、长链推理与验证，不以讲题数量判断进步。 |

## 04  制作流程与版式要求

只保留必要步骤：核资料、写判断、配措施、审核、发送与归档。

### 1. 制作顺序

| 步骤 | 具体操作与产物 |
| --- | --- |
| ① 资料核对 | 按内部工作单整理本阶段记录，核对姓名与时间；提取历史可比记录，保留原始来源。输出缺失清单，不先写结论。 |
| ② 判断与取舍 | 区分事实、判断、待核查和计划；选出当前优势及1–2个优先问题。旧问题标明持续、改善、反复、已稳定或待核查，并附依据。 |
| ③ 正文成稿 | 按五板块填写家长版。每个核心问题配对应措施及复查点；不能成立的比较句、第二问题、家长配合句应直接删除。 |
| ④ 双重审核 | 先查内容真实性与逻辑，再查身份、日期、版式和隐私。AI自审仅作辅助；由任课教师确认后形成通过版本。 |
| ⑤ 发送与归档 | 只发送已通过的家长版；归档阶段事实、变化、问题、计划与复查点。保存历史记录，不用本次结论覆盖过去阶段。 |

### 2. 家长版版式

| 项目 | 执行要求 |
| --- | --- |
| 页面与结构 | 默认A4横向、1页；保留机构标志、五列信息栏与五个正文板块。在家长版副本的标题下填写反馈日期和任课老师，保留五个正文板块。 |
| 字号与行距 | 标题20–24磅；正文以11磅为基准，不因塞进一页而缩小到10.5磅以下。常规中文字体，段内行距约1.15–1.3倍。 |
| 视觉强调 | 沿用橙色表头与浅色标签栏。正文深色为主，每段最多突出一句关键结论；避免整段标红、密集加粗或装饰性符号。 |
| 表格与分页 | 行高采用最小值而非可能裁字的固定值，正文行不跨页拆分。超页先删重复和套话；确有必要保留的信息，经教师确认后允许两页。 |
| 最终检查 | 实际渲染或打印预览逐页检查：标题、日期、中文字符、换行、表格、页边距均正常，无裁切或重叠。换设备或导出格式后重新检查。 |

### 3. 文件与隐私

家长版按“姓名_阶段学情反馈_反馈日期_版本.docx”命名，返修递增版本。内部工作单单独保存，以原始记录辨明本期材料。

发送前移除所有【占位符】、可删提示、内部证据编号、审核意见、批注和修订痕迹。检查页眉页脚、内容控件及隐藏字段中是否残留其他学生信息。仅保留本次沟通所需资料，不加入无关家庭隐私或其他学生比较。

## 05  发送前审核与处理结论

不采用复杂评分；有硬性问题就退回，修订完成后再放行。

### 1. 十项审核清单

| 编号 | 通过条件 |
| --- | --- |
| A1 身份与时间 | 学生姓名、年级、科目、反馈日期和任课老师准确，所用记录属于本期。 |
| A2 事实依据 | 关键优势、问题和变化均能追溯；数据和转述来源清楚，无编造。 |
| A3 判断边界 | 讲过、提示后完成、独立完成、稳定和迁移未混淆；无无依据的因果归因。 |
| A4 纵向衔接 | 有可比证据才写变化；无证据明确待核查，未把旧问题直接当本期现状。 |
| A5 问题聚焦 | 有明确问题时聚焦1–2项并写到具体表现；没有明确问题时写必要核查点，不制造不足。 |
| A6 问题与措施 | 每项核心问题或必要核查点均有对应安排，没有只提问题不处理。 |
| A7 可执行与复查 | 教师确认责任分工、任务量或频次、复查时间与达标表现；后续推进有条件。 |
| A8 全文一致 | 信息栏、正文、定位与总结不矛盾；总结没有未经论证的新结论。 |
| A9 沟通措辞 | 具体、尊重、易懂；不贴标签、不责备家长、不承诺分数或排名提升。 |
| A10 成品与隐私 | 实际预览通过；无占位符、批注、旧姓名、内部材料或明显格式问题。 |

### 2. 审核状态与放行规则

通过：十项均满足，或不适用项已说明理由，且任课教师确认事实与计划，可以发送。身份、事实真实性和隐私不得以“不适用”跳过。需修改：证据基本足够，但措辞、对应关系、计划或版式有问题，修订复核通过前不得发送。待补资料：身份、阶段、关键结论依据或实际安排缺失，先补资料，不用润色替代核查。

> 硬性退回：错人或时间范围错误；虚构分数、表现、变化；把提示后完成写成独立稳定掌握；确认问题却无对应处理；未经确认的安排写成承诺；泄露其他学生信息或保留内部审核内容。不能靠其他项目表现良好抵消。

### 3. 上传样稿中的证据边界示例

样稿用“继续预习集合、逻辑用语”支持“学习容量和知识承接能力较好”。前者能支持教学范围，但仅凭这句话不足以验证后者；正式反馈应补具体作答记录，或收紧为“本阶段在衔接计算之外已预习集合、逻辑用语，独立掌握及迁移情况仍需复查”。

样稿写“目前未暴露明显的基础性问题”，并安排后续检查。可保留这一谨慎方向，表述为“现有反馈中未记录明显基础性问题；计算保留、符号表达和新题型迁移仍需后续复查”。这是对材料支持范围的说明，不是否定原教师判断，也不是新增学生事实。

## 06  AI复用指令与档案衔接

先保留证据，再压缩表达；生成与审核分两次完成。

### 1. 生成指令

> 请依据我提供的本阶段课堂记录、作业／检测、历史档案和已确认教学安排，制作一份家长可读的阶段学情反馈。保留基本信息栏及“整体、优势、问题、措施、总结”五板块，正文目标约500–700字。
> 先核对学生身份、所涉学习阶段与资料完整性。若身份、阶段、具体学习事实或下一步实际安排缺失，先输出缺失项及待教师确认的问题，不产出可发送版本。
> 区分事实、判断、待核查和计划；保留提示程度、独立性、任务范围及信息来源。只有历史任务可比时才写进退变化；无资料不补成绩、题量、原因、掌握程度或进步结论。
> 有记录时提炼1–2项优势与核心问题；没有明确问题就写必要核查点。每项问题配教师确认的任务、责任人、执行量或频次、复查时间和达标表现。AI建议单列内部待确认，不写成既定安排。
> 输出：①家长版草稿；②内部依据与待确认项，和家长版明确分隔。证据不足的段落收紧表述，不用套话填满；生成结果不得自行标记已通过审核。

### 2. 独立审核指令

> 请对照原始资料审核这份阶段反馈，不先替作者润色。逐项检查A1–A10，重点查：人物与阶段是否正确；关键判断是否有依据；是否把讲过／提示后完成夸大为独立稳定掌握；历史比较是否可比；每个核心问题是否有措施；计划是否已确认且可复查；是否有矛盾、标签或提分承诺。
> 按“审核状态—必须修改项—待补资料—可直接替换的表述—需人工完成的版式／隐私检查”输出。对无法核实的内容标待确认，不以更肯定的措辞替换。未实际打开最终文件，不得声称版式检查通过；教师未确认前，不得建议发送。

### 3. 通过后的最小归档记录

| 字段 | 写入内容 |
| --- | --- |
| 阶段与依据 | 月份、单元或课次范围，以及实际学习内容、关键事实及原始记录位置。 |
| 纵向变化 | 与哪次记录比较、任务条件有何差异、变化结论或待核查状态。 |
| 问题与安排 | 当前1–2项优先问题、教师确认的措施与责任分工。 |
| 复查与版本 | 复查时间、达标表现、反馈版本、审核人与通过日期。 |

只有任课教师确认后才把正式结论写入学生档案；原始事实、历史阶段和待核查项分别保留。下次阶段反馈从本次复查点接续，不重复沿用未核实的标签。

### 4. 配套文件使用

填写“资料采集与审核单”，据此完成家长版模板，再按十项清单审核。本项目以此 v1.1 Markdown 为现行规范。历史下载包内的 Word 规范对应 v1.0；无需另建数据库、复杂评分表或多套学生版本。
