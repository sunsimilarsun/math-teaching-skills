# 阶段学情反馈：资料采集与审核单 v1.1

> 教师内部使用，不随家长版发送。可以删去多余空行；没有资料写“未提供／待核查”，不要猜填。三个事实空行仅供填写，不是必须凑满的数量指标。

## 一、基础信息与输入完整性

| 字段 | 填写内容 |
| --- | --- |
| 学生姓名／年级／科目 | 【填写】 |
| 本期材料范围（内部） | 【月份、单元或课次；确知时可记起止日期】 |

最低输入检查：身份、阶段、实际学习内容、至少一条具体学习事实及完成条件、下一步实际安排。缺少身份、阶段、具体事实或安排时，不进入可发送版本制作。

## 六、发送前审核

- [ ] A1：姓名、科目、年级、反馈日期与任课老师准确，所用记录均属于本期。
- [ ] A2：优势、问题、变化和数字均有依据，转述来源保留。
- [ ] A3：完成条件清楚，无把讲过、提示后完成夸大为独立稳定掌握。
- [ ] A4：历史对照可比；无资料时已删去升降判断并说明待核查。
- [ ] A5：有明确问题时聚焦有依据的1–2项；没有明确问题时写必要核查点，不制造不足。
- [ ] A6：每个核心问题和必要核查点都有对应安排。
- [ ] A7：责任、任务、量或频次、复查时间及达标表现已由教师确认。
- [ ] A8：信息栏、定位、正文与总结一致，无新冒出的结论。
- [ ] A9：语言具体尊重，无无据归因、固定标签、责备或提分承诺。
- [ ] A10：最终文件已实际预览，无裁切、占位符、批注、修订及内部信息。

不适用项应记录理由，不以随意勾选代替审核。身份、事实真实性和隐私不得以“不适用”跳过。只有实际打开最终文件后，才能确认版式通过。
