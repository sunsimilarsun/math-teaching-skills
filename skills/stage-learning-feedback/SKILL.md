# 阶段学情分析与反馈

家长读完应知道孩子这段时间做过什么、能独立做到哪一步、接下来教师怎样教和复查。用户指定五板块、单页横版或阶段学情分析表时使用本 Skill。若指定三页机构学员学习报告，用 `learning-report-author`；同一份试卷也可作阶段证据，重点是逐题评分时用 `math-exam-analysis`；单周五段反馈用 `weekly-student-feedback`。只做教师内部诊断、追问或复测设计时可使用 `math-learning-diagnosis`。

## 找到本次要用的原件

从当前教学库向上找到同时含 `数学教学/`、`Template/`、`规范/` 的 Markdown 根，或使用用户提供的现行工程位置。相对该根读取：

- `规范/档案/阶段学情反馈/02_阶段学情反馈_制作与审核标准_v1.1.md`，用于阶段判断、各栏内容及 A1–A10 审核。
- `Template/学生管理/阶段学情反馈/03_阶段学情反馈_资料采集与审核单_v1.1.md`，用于教师核证、存疑事项和复查。一次短改可就涉及的条目核对。
- `Template/学生管理/阶段学情反馈/01_阶段学情反馈_家长版模板_v1.1_重点标红.docx`，制作家长 Word 时打开并复制到交付位置；已有稿的定向修改在该稿副本上进行。

若路径不同，按文件名搜索当前项目、用户提供的文件夹，核对标题、版本和用途。历史下载包提供 Word v1.1 和旧版标准，在其他设备仅拿到旧包时，沿用本 Skill 的现行署名和日期口径。无需为日常成稿查找网上模板。仅有课堂材料时可先做有依据的分析或文字草稿。如缺正式模板或审核规范，说明缺哪件、影响哪一步，保留相应版式或规范验收为待核。

## 家长稿共用写作规则

- **用动作替代评价。** 写学生在具体任务中做了什么，哪一步独立完成，哪一步用到了提示。记录只有结果时就写结果，不补过程或推测原因。
- **不强行凑首尾。** 保留规定的称呼、栏目和固定文字。可改的正文从本栏要说的事实或安排写起。一句开场评价或结尾展望如果没给家长带来新信息，就省掉。

## 从原始记录写到五个栏目

1. 按学生和本期月份、单元或课次核对材料归属、实际学习内容、至少一条具体任务及完成条件、教师确认的后续安排。可用课堂原始记录、作业、测验、复查及明确标记来源的转述。周反馈与课堂记录转述同一次作答时合为一次。未提供考试成绩仍可成稿。身份或阶段无法确定时，先澄清学生或材料归属；其余必要资料缺失时先列最少补充项，可交付已能确认的片段。
2. 用内部工作单对照前后同一学习目标，记录日期、题目是否见过、难度、时限、独立或提示程度、具体结果。条件可比才表述变化。已见题订正、接受关键提示、换新题独立作答、隔时复测分别保留。旧问题未经本期复查就保留其原日期；不同来源冲突时写清条件并给出能区分两种解释的复查，不强判进退。
3. 写五栏。**整体**写本期范围与当前表现，有可比证据时才写变化。**优势**举一项能追溯的任务，说明孩子做到哪一步。**问题**选影响后续的一两处具体卡点；材料尚未暴露问题就写待验证项。**措施**逐项给出目标、责任人、任务、量或频次、复查时间及可观察的达标表现。未经教师确认的措施放进内部建议。**总结**只收束已有依据的成果、下一步重点及推进条件。正文约 500–700 字为预算，保留个体证据和完成条件优先于凑字数。
4. 家长版标题下仅列反馈日期和任课老师，按本次材料或项目约定填写任课老师。无需列阶段起止日期；已有月份、单元或课次足以定位时即可成稿。用熟悉的题型、动作和结果来解释学情定位；教师、学生、家长的分工按实际安排写。内部工作单保留来源、待核原因、提议与审核记录。完成初稿后先做下文的出稿前文风校对；生成或改 Word 时按[模板填充与复核](references/template-and-review.md)实做并预览。只要求审核时，直接对照原始记录检查原稿，指出所在栏目、必须修订之处和可替换文字。
5. 按现行标准 A1–A10 对照复核，说明“待补资料”“需修改”或经教师确认后的“通过”。生成稿可标“草稿，待教师复核”；可从本期可核实的课堂记录提取事实，后续安排按教师已确认的范围表述，不代签审核。家长版与内部材料分别交付。制作、正式归档、对外发送按各自授权执行；归档保留阶段日期和历史记录。

## 出稿前文风校对

五栏初稿写完、进入审核和版式预览前，像和家长面谈一样读一遍，看家长能否听清孩子先前和现在各能做到哪一步，哪些还需复查。成稿用自然的书面语。只改本次可改的文字。仅审核时指出所在栏目并给替换句，仅改版式时保留原文。

- **主语能省就省。** 连读前后两次表现，省去能从上下文认出的姓名、“孩子”和人称代词。只有省略后分不清是谁做的，才保留姓名或称呼。保留“经提示”“独立完成”等作答条件。
- 前后变化用同一项任务来讲，写清当时做到了哪一步、得到过什么帮助。只有本期记录时直接写本期表现。遇到“进步明显”“综合能力稳步提升”，核对前后任务是否可比、各次提示是否清楚。只写材料支持的具体变化；缺少可比记录时删去升降结论。
- 例如，上次同类新题需要老师提醒才列出分母限制，这次两道新题都能独立写出。可写“上次做这类题时，还要老师提醒才会写出分母不能为零。这次做两道新题时，都自己写出了这个条件。”这就足以肯定这一步的变化。还没隔时复查，总结就把独立完成的判断限定在这两道新题上。未确认的复查安排留在教师工作单。
- 连读“整体”和“总结”。整体交代本期范围和表现，总结留下有依据的阶段收获与下一步重点。比较前后需要的时间词和提示条件要保留。只为凑排比的过渡、重复的赞叹和宽慰家长的套话可以删。改完对回时间、次数、独立程度和复查状态，核实计划与结果的区别，保留五栏、反馈日期与任课老师。
